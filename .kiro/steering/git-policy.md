# Rule: Git Policy

## Không tự động chạy lệnh git

Không được tự ý chạy bất kỳ lệnh git nào, bao gồm:
- `git add`
- `git commit`
- `git push`
- `git merge`
- `git rebase`
- `git reset`
- `git checkout`
- Bất kỳ lệnh git nào khác

## Thay vào đó

Sau khi hoàn thành thay đổi, chỉ cần thông báo ngắn gọn những file nào đã được sửa/thêm để người dùng tự review và commit.
