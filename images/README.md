# 📁 Thư mục Hình ảnh

Hãy đặt ảnh vào đúng thư mục:

## 📂 products/
- Ảnh sản phẩm đồ chơi (tên gợi ý: `product-1.jpg`, `product-2.jpg`, ...)
- Kích thước khuyến nghị: **600x600px** (vuông)

## 📂 banners/
- Ảnh banner chính hiển thị ở đầu trang
- Kích thước khuyến nghị: **1200x600px** (ngang)

## 📂 icons/
- Logo thương hiệu hoặc icon nhỏ
- Kích thước khuyến nghị: **200x200px**
